## Learning Objectives

*After this lesson, students will be able to:*

1. State Bayes Theorem (the probability law)
1. Describe questions that can be answered by Bayesian inference
1. Understand the steps to set up a problem to be solved with Bayesian techniques
1. Compare and contrast Bayesian and Frequentist inference
1. Implement simple Bayesian models via the PyMC library

## Lesson Outline

- I. Review: The "AND" probability law and Bayes' Theorem
- II. Bayesian Statistics
- III. Bayesian problems via PyMC
